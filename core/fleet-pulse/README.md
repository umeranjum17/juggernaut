# fleet-pulse
- `wiring.sh [--dry-run] <home>` installs nothing into the home's tracked `bin/` (the refresh runs the extractor from this folder); when `state/fleet-pulse.check.sh` still globs only `data/jg-retro-*/report.md` under the main home, it retargets that wake to `bin/fleet-retro-due.sh`, and when it still greps session logs for Fable itself, it retargets that wake to `bin/fleet-fable.sh`.
- When that check's 2h report still counts landings as merged PRs only, `wiring.sh` also retargets the report onto the trunk era, all blocks or none (a check with the report but not every block in the known form is left as it is and the missing blocks are named, exit 1): landed, live and rtl come from `bin/trunk-pulse.sh`, asks>2h from `bin/lead-asks.sh`, and the open/working/dry row from `../fleet-flow/bin/jg-flow-check.sh` with `JG_MAIN_HOME` set to the home.
- A wiring run that changed the check's bytes re-registers it with the home's `bin/jg-check-register.sh` before it exits, even when a later block then refuses, so the watcher keeps accepting it with no hand registration; a home with no register script is refused before anything is edited.
- `bin/trunk-pulse.sh <home> <since-epoch> [<now-epoch>]` reads the home's `data/trunk-landings.tsv`, `trunk-live.tsv` and `trunk-releases.tsv` and prints `landed live ready_min`: landings and live moves since the epoch, and the minutes the oldest landed commit has waited to go live (`-` when none waits; a landing stops waiting once its project's newest live row names it or a later landing, or a release followed it). A home with neither landing nor live records exits 1 printing nothing, so the pulse keeps its merged-PR count.
- `bin/lead-asks.sh <lead-status-file> [<now>] [<min-age>]` counts a lead's asks to Main open longer than the age (default 7200 s): still open by `bin/jg-classify.sh own-open-decisions` (the wake drain's fold), keyed, and raised by the lead rather than a relayed captain hold or a supervisor library's key. A classifier that cannot run exits 2 printing nothing.
- `bin/fleet-homes.sh <main-home>` prints every known home once: the main home, homes listed in `data/squad_leads.md`, and sibling `~/.treehouse/juggernaut-*/*/juggernaut` homes (override the treehouse root with `JG_TREEHOUSE`).
- `bin/newest-retro-report.sh <main-home>` prints the newest `data/*retro*/report.md` across those homes, by mtime.
- `bin/fleet-fable.sh <main-home>` wakes (at most every 15 min via `state/.fleet-fable.last`) when a Claude session log from the last 20 minutes ran Fable and the installed `core/claude-model-guard` would refuse it: a session in a task's worktree (`state/*.meta` in those homes), or in the folder of a quota-failover one-line test for a task (`jg-probe-<task-id>.XXXXXX`, named by `core/quota-failover/jg-probe-folder-lib.sh`), is skipped when the guard's `allowed <task-id>` passes, so its `allow-tasks` is the one list; a session no task owns, a route-level test among them, is named by its folder, and a guard copy too old to answer is named instead of trusted. With no guard installed it stays silent.
- `bin/fleet-retro-due.sh <main-home>` wakes once when that newest report is missing or at least 60 h old (at most every 12 h via `state/.fleet-retro.last`); the pulse check calls it so a retro that ran in another home stops the early ask.
- Retro refreshes current redacted captain chat with `JG_HOME=<main home> <addons>/fleet-pulse/bin/chat-tsv-refresh.sh`, appending only new rows to private `<main home>/data/chat.tsv`.
- Set `CHAT_TSV_TRANSCRIPTS` to override the Claude projects directory; the refresh refuses to run without `JG_HOME`, and the extractor refuses to write unless Git confirms `data/chat.tsv` is ignored.
- Rows contain UTC ISO-8601 `at`, session-cwd-basename `work` (or `main` for the home checkout/missing cwd), and flattened `text`; metadata, sidechains, tool results, commands, reminders, injected wake text, XML wrappers, mirrors, summaries, and artifact wrappers are filtered while human text outside wrappers is retained.
- Every drop and truncation reason is counted on stderr without message text; secrets/codes are redacted and text is capped at 4000 characters with `[truncated]`.
- The output and sidecar are mode 600, the data directory is mode 700, and `unwiring.sh <home>` removes only a `bin/chat-tsv.py` copy left by an older wiring.
## Check
- `bash tests/fleet-fable.test.sh` reproduces an old inline Fable wake firing for an allowed `fable-*` task, retargets it with `wiring.sh`, and shows the check then quiet for allowed tasks and their quota-failover tests and still waking for an unlisted task (and its test), a taskless session, a route-level test and a stale guard, with the real guard in throwaway paths.
- `JG_MAIN_HOME=<home> bash run-fable-proof.sh` (done-done journey `fleet-pulse-fable-allow`) runs that test and the guard's, then dry-runs `wiring.sh` on the live home and prints the live guard's allow-tasks, writing nothing there.
- `bash tests/newest-retro.test.sh` covers newest-across-homes, older-main/newer-sibling not due, none or all-old due, wake-mark suppression, and non-`*retro*` dirs ignored, with disposable fixture homes.
- `bash tests/chat-tsv.test.sh` covers wrapper filtering, mixed human text, audit counts, redaction, truncation, permissions, idempotency, and incremental refresh with disposable fixtures.
- `bash tests/trunk-pulse.test.sh` runs a fixture pulse check with the old 2h report blocks before and after `wiring.sh`: the trunk home goes from landed0/open unknown to its landed, live and rtl figures, only the open keyed lead ask past 2 h counts (answered, superseded, keyed-done, unkeyed, captain-hold, continuity and young asks do not), a merged-PR home still counts its merged PRs, and the pin-back, release and no-records rules hold; done-done journey `fleet-pulse-trunk-landed` (`run-trunk-proof.sh`) adds a read-only dry run on the live main home.
- `bash tests/gate-audit.test.sh` covers pass/card ordering, later failure, card-only/missing rows, and number-only matching.
- `bin/gate-audit.sh <checks-gate.log> <pr-url>...` prints each URL with `pass` only when its latest non-card row says pass; otherwise it prints `bypass`.
