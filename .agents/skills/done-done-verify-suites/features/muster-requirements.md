# Muster requirements and plan directions

The [Muster requirements suite](../suites/muster-requirements.md) covers the signed pack, the plan check and the frozen slice order.
Run `done-done run muster-requirements` from the repository root.

Sources: `tests/jg-muster-requirements.test.sh`, `core/muster/approval.py`, `bin/jg-muster-approval.sh`, `bin/jg-war-room.sh`, `bin/jg-swarm.sh`, `core/agent-cli/contract/muster-approval.json`, `.agents/skills/muster/formats.md` and `.agents/skills/op-order/SKILL.md`.

The [engineering practices suite](../suites/muster-engineering-practices.md) uses `done-done run muster-engineering-practices` to check the signed standards.
Its sources also include `journeys/muster-engineering-practices.sh` and `.agents/skills/muster/templates/ways-of-working.md`.
