# Agent CLI contract

Run `done-done run agent-cli-contract` for the default suite, or use the [contract suite](../suites/agent-cli-contract.md) to include changed tests.

The [journey](../../../../journeys/agent-cli-contract.sh) drives `bin/jg` and `bin/juggernaut-axi` in isolated homes.
It checks the vendor probe help, a ticket body update from a file, a keyed radio answer, and creation of a local public follow-up obligation.
It also checks the [watcher command policy](../../../../bin/jg-arm-command-policy.mjs) and [pre-tool hook](../../../../bin/jg-arm-pretool-check.sh) deny background arming, and the [test runner](../../../../bin/jg-test-run.sh) reports a named test without live opt-in as skipped.
The watcher stream case releases the fixture only after reading startup on stderr and checks the final envelope.
