# Agent CLI contract

Run `done-done run agent-cli-contract` for the default suite, or use the [contract suite](../suites/agent-cli-contract.md) to include changed tests.

The [journey](../../../../journeys/agent-cli-contract.sh) drives `bin/jg` and `bin/juggernaut-axi` in isolated homes.
It checks vendor probe, backlog, and away contract help, a ticket body update from a file, a keyed radio answer, and creation and work binding of a public follow-up obligation.
The report cases compare the JSON bearings snapshot with PR discovery and with all decisions against the direct script on fixture data.
These forms exercise the [dispatcher](../../../../core/agent-cli/dispatch.sh), [report contract](../../../../core/agent-cli/contract/e6report1.json), and [worker contract](../../../../core/agent-cli/contract/worker.json).
It also checks the [watcher command policy](../../../../bin/jg-arm-command-policy.mjs) and [pre-tool hook](../../../../bin/jg-arm-pretool-check.sh) deny background arming, and the [test runner](../../../../bin/jg-test-run.sh) reports both named OpenCode and Pi tests as skipped when live opt-in is unset.
The watcher stream case releases the fixture only after reading startup on stderr and checks the final envelope.
