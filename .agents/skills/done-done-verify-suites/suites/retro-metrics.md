# Retro metrics

Retro metrics: run `done-done run retro-metrics`; the real `jg-retro-metrics.sh` over a fixture home proves the one first-pass definition (bots excluded, reverted and escaped excluded, stored with its count), the window split against the prior window, that a stored retro line is read back after the source records change, and that a missing home or unknown retro is refused.
