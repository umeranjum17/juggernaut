# Answer route

Answer route: run `done-done run answer-route` (it names the pinned `bd` and `dolt` and writes the log into `$DONE_DONE_EVIDENCE_ROOT`); the real `bin/jg-answer-route.sh route` reads an answered card from the board and takes each option of the answer to one end with no model turn: an option the card marks `executor=worker` gets one ticket filed from its own text, one brief with its Task sections filled, and one approval record that the real `core/auto-dispatch/dispatch.sh check` then reads as startable; a card with no executor field, and an option whose text discards work whatever the card says, get one supervisor step and no ticket; a dated deferral gets one owner ticket filed and held by `bin/jg-captain-hold.sh hold --until` to the date it names; a status-quo option is recorded, an answer that names no option is recorded and reported, and a repeat of the same answer writes nothing. The real `bin/jg-board-answers.sh check` calls it at answer time, so an answer starts work by itself, and `bin/jg-question-card.sh post --executor <option>=worker|supervisor` writes the field the router reads, recording it beside the board and refusing an option the card does not carry (screen: none).
