# Trunk self-repair

Run `done-done run trunk-self-repair` to drive the real trunk verify, release CI watch and automatic release through their red paths.
The tests confirm that each failure stays recorded, one repair ticket reaches auto-dispatch, and repeat observations or an interrupted approval produce one lane.
The fixture stubs the forge and spawn.
The sealed run captures lint in `lint.log` and test output in `<run-id>.log` (screen: none).
