# Beads read facts

Read facts: run `done-done run -- bash tests/jg-beads-read.test.sh` to drive the real `bin/jg-beads-read.py` on a throwaway home's tickets tables; it proves the rev moves on a row write, a label, a comment, a dependency, a dependent and a parent write and stays put on a read, the cursor list walks every open row once with closed rows and gates left out and the same ids as `list`, the board read returns, in one query, each open row and each row closed since a cutoff (no gates, no row closed before it) exactly as `show` gives it, rev included, `board --all` holds an older closed row, and the history names the changes that altered one ticket and the columns each changed (screen: none).
