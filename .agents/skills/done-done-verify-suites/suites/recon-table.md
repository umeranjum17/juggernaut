# Recon table

Recon table: run `done-done run recon-table` (`bash journeys/recon-table.sh`, which runs `bin/jg-machine.sh check recon`, `events recon` and `tests/jg-machine-recon.test.sh` and writes its log and `steps.json` into the run's folder); it lints `core/machines/tables/recon.tsv` (4 states, 8 moves, each with a test) and drives a Recon through the real owner script `bin/jg-recon-handoff.sh`: draft, critic ticket assignment (it survives a restart, only the assigned critic's verdict counts), critic verdict with gaps, revise, verdict clear and accept, each tied to the report hash, and a verdict for an older hash is refused and cannot close the newer draft ; it also runs `tests/jg-machine-ticket.test.sh` (the quick and standard proving paths) and `tests/jg-lavish-guard.test.sh` (a scout's done line makes the move `submit-draft`, with no commit) (screen: none).
