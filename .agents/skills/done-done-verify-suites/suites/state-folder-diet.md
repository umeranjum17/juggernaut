# State folder diet

State folder diet: run `done-done run state-folder-diet` (`bash journeys/state-folder-diet.sh`); it leaves a fixture task with a file of each per-task kind that `bin/jg-task-files-lib.sh` lists (slice 1: `probe-at`, `account-probe-at`, `exit`, `check-trust`, `check.sh`, `model-relaunch`, `land-next`, `models`; slice 2: `turn-ended`, `busy-state`, `busy-gen`, `control-relaunch`, `control-relaunch.note`, `control-relaunch.meta-prior`, `control-relaunch.brief-prior`, and the `git-hooks` directory; slice 5: `grok-turnend-token`, `kimi-turnend-token`, `muse-session`, `muse-session-current`, `cursor-session`, `limit-prompt-gen`, `composer-dialog`, and the `pr-poll-merge-notified.lock` directory), runs the real `bin/jg-teardown.sh`, and prints the count of kinds before and after (40 to 0); `bash tests/jg-teardown.test.sh` proves the same removal on the already-cleaned path and on a landed teardown.
