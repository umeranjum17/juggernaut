# Dispatch start result

Dispatch start result: run `done-done run -- bash tests/jg-auto-dispatch.test.sh` and `done-done run jg-spawn-lock-deferral` with `JG_BEADS_TEST_BD` and `JG_BEADS_TEST_DOLT` naming the pinned builds; with the switch on, the check `core/auto-dispatch/dispatch.sh` records what each spawn really did in `data/auto-dispatch/<id>.start.<attempt>` (exit 0 with the lane record is started, exit 75 is deferred, anything else is a failure with the spawn's last line as its cause), so a ticket whose spawn said wait (a full pool or a locked task set, which the real `bin/jg-spawn.sh` now answers with exit 75 and a `deferred:` line) is started again by the next beat under the same approval, a refused start waits for a new approval, a lane that already runs is never spawned again, and a restart or two runs at once start a ticket once; `bin/jg-machine.sh check dispatch-start` lints the table of these states (screen: none).
