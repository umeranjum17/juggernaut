# Herdr backend core (Go)

Herdr backend core (Go): run `bash tests/jg-herdr-go.test.sh` (or `done-done run -- bash tests/jg-herdr-go.test.sh` with the log written into `$DONE_DONE_EVIDENCE_ROOT`); it sources `bin/backends/herdr.sh`, which forwards its decisions and JSON reads to `core/herdr`, and proves the release floor, the presentation preference, agent names, the pane, workspace and agent reads over canned answers, and that a core that cannot run exits 2 rather than answering. For a port or change of a reader, run `core/herdr/replay.sh <base herdr.sh> <recorded dir>` (and `--control`, which must fail) over answers recorded from a named lab session (`bin/jg-herdr-lab.sh`, never the live session); `core/herdr/README.md` names the replay, and the real-Herdr suites (`tests/jg-backend-herdr-*-e2e.test.sh`, `tests/jg-backend-herdr-smoke.test.sh`) prove the live adapter.
