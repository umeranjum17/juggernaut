# Merge evidence one card per PR

[Merge evidence one card per PR](../features/merge-card-one-card-per-pr.md): run `bash merge-card/tests/merge-card-e2e.sh`; it uses a fixture board and stub sign-off-axi, proves a new head leaves one live card and archives the old one (posted one at a time, never `--replace`), two PRs keep two cards, and the internal-change title names repo and PR. A merge never dirties the project clone: `done-done run merge-card-clean-clone` (`merge-card/run-clean-clone-proof.sh`, the real merge-card and sign-off-axi; the e2e file asserts the same) posts against a real throwaway git clone with done-done's post opt-in on, and `git status` must stay clean, the cards must sit on the board, and a stray `.sign-off/` in the clone must be reported and left in place. Also run `bash merge-card/tests/real-board.test.sh` for the same journey with the real sign-off-axi on a seeded temp board, plus another filer's cards for the same PR: the post and `merge-card/one-card-per-pr` keep the newest valid proof live and archive the rest.
Also run `bash owner-rules/tests/owner-rules-gate.test.sh`: a `screen: none` pull request takes the text-only card path with no capture (the gate's first line says so), a claim citing a file outside the sealed run is redirected to the run's own capture with one line naming it, and a claim no sealed run supports is still refused.
