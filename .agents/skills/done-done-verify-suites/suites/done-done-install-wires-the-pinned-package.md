# done-done install wires the pinned package

done-done install wires the pinned package: run `done-done run tool-wiring` (`journeys/tool-wiring.sh`, which runs `tests/jg-tool-wiring.test.sh` and writes its log and steps into `$DONE_DONE_EVIDENCE_ROOT`); on a clean throwaway HOME the real `bin/jg-bootstrap.sh install done-done` writes the brief include and places the merge gate, whether the package ships `integrations/firstmate/` (done-done-axi 0.6.27, the pin) or `integrations/juggernaut/`, and exits 0 (screen: none).
