# A worker's own question is answered with no Main turn

A worker's own question is answered by its home: run `done-done run decision-handler` (`bash core/decision-handler/tests/decision-handler.test.sh`); a worker asks with the real `jg ask` from its worktree and the real `core/decision-handler/decision-handler.sh tick` reads it through the real status classifier, asks a plan-only advisor once with the accepted intent, and sends one steer to that worker that closes the question, and a replay, a restart or a duplicate tick sends nothing more. A failed send keeps the same pick and delivers it once when the endpoint is back. A question or option that names a credential, a discard, a waived proof, a scope or a release, the captain's own question, a validation finding, advice that names no option and an advisor that says it is the owner's call all stop at the existing authority with no steer. The advisor and the steer endpoint are recorders; the live advisor model is not exercised (screen: none).
