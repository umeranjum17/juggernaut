# Wake schedule honoured end to end

Wake schedule honoured end to end: run `done-done run wake-schedule` (which runs `bash tests/jg-wake-schedule.test.sh` then `bash tests/jg-wake-batching.test.sh`); on fixture homes with no `config/wake-routing` it proves a routine item raises no wake and arrives in one digest (once per `set digest-minutes`, never empty), an away-mode heartbeat over an unchanged fleet is silent while a changed fleet wakes, a `done` carrying a key stops that key's re-ping, and a captain answer, red gate, host alarm, stuck worker and finished deliverable still wake at once; it also proves the four c-5 wake misses settle quietly (a gap open under an hour, the fleet-pulse 2h report, a race-lost relaunch notice in a restart pass, a lead supervision notice inside its restart grace window) and still wake in the real case (a gap open an hour, another fleet-pulse failure, the notice outside a pass or past the grace) (screen: none).
