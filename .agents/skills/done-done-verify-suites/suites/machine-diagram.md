# Machine diagram

Machine diagram: run `done-done run machine-diagram` (`bash journeys/machine-diagram.sh`, which runs `tests/jg-machine-diagram.test.sh` with `JG_DIAGRAM_REQUIRE=1` and writes its log, `steps.json` and the drawn charts into the run's folder); it needs the WebAssembly Graphviz that `toolchain.versions` pins (`npm install -g @viz-js/viz@<pin>`, or `JG_VIZ_DIR` set to a folder that holds it). It draws the 11 statechart tables of `core/machines/tables` with `bin/jg-machine.sh diagram` in a wide and a narrow layout, and every chart passes the chart check (no crossing arrow, every arrowhead, every label on its plate, no overlapping label, no label on a state, no narrow chart over 450 pt); a fixture table whose arrows must cross fails with the two arrows named, a state whose timeout names no alert of the alert table fails, and `escalation` prints who is told first, next and by a board card. It reads only shipped tables and generated fixtures (screen: none, the charts are SVG files in the run's folder).
