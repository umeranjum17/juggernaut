# Parallel landing batches: several batches test at once and a red batch sends back only its bad lane

Landed lanes above the green pin: run `done-done run -- bash -c 'set -e; bash tests/jg-trunk-parallel-batch.test.sh > "$DONE_DONE_EVIDENCE_ROOT/trunk-parallel-batch.log" 2>&1'`; over a fixture home with real git and the real `bin/jg-trunk.sh verify`, it proves that the stack is cut into `verify-width` batches whose gate runs overlap and that all green moves the pin to the tip; that a red batch is searched with probes at once and only the commit that added the red is reverted, with every other lane kept and the pin left below the red; that width 1 or one heavy slot (`core/lane-scale/fleet.sh`) keeps the runs one after another and finds the same commit, and gives each slot back; and that a stack of 16 is traced in 7 gate runs (screen: none).
