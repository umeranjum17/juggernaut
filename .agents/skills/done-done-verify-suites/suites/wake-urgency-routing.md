# Wake urgency routing (Go)

Wake urgency routing (Go): run `bash journeys/wake-routing.sh` (or `done-done run wake-routing`); it runs `tests/jg-wake-router.test.sh` and `tests/jg-wake-route.test.sh`, which build `bin/jg-wake-core.sh` and prove the class of every recorded event, that a ship's PR-ready `done` line settles (`silent@merge-owned`) only when its record names the PR and the merge watcher owns it while every other done, failed, blocked, needs-decision and Recon line keeps waking, the pattern grammar, the rule files layered in priority order, the status-file rule, the queue-quiet bound, the re-alert dedupe and the silence cap, and `now` where the router cannot run. For a port or change of the rules, replay the previous shell against the Go command over the recorded events (`core/wake/README.md` names the replay and its control run); `bin/jg-wake.sh next` then shows the classes on a real queue.
