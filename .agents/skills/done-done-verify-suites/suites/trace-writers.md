# Trace writers

Trace writers: run `done-done run trace-writers` (`bash journeys/trace-writers.sh`, which runs `tests/jg-trace-writers.test.sh` on a real Beads store with `bd` and `dolt` from the path, or from `JG_BEADS_TEST_BD` and `JG_BEADS_TEST_DOLT`); `jg-backlog.sh trace record <task or ticket> <kind> <ref-kind> <ref> --source <source> --at <time>` finds the row by a task id or a ticket id, records the provenance event first and the time on the row second, adds nothing for a repeat, refuses a moment moved back and only grows the evidence list; the delivery tick's ready step (`bin/jg-ready-trace.sh`) records `commit` and `ready_at` for a lane's `done` line, `resume` and `resumed_at` when the last line is no longer `done`, and a newer `ready_at` for a later `done`, with no store call for a quiet tick; the merge's post-merge step records the receipt it read as a `used` event with its verdict.
