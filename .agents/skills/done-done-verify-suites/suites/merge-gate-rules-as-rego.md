# Merge-gate rules as Rego (`policy/gate/`)

Merge-gate rules as Rego (`policy/gate/`): run `bash tests/jg-merge-gate-policy.test.sh` (or `done-done run merge-gate-policy`, which runs it). It runs `opa test policy`, then 40 pull requests through the real `jg-checks-lint.sh` and the guard host's `eval` door, recorded `checks-gate.log` rows through the owner-rules gate's fact gathering, 62 homes through the real owner-rules merge gate (`core/owner-rules/tests/gate-matrix.test.sh`), and 41 task records through the completion-receipt acceptance (`core/receipts/tests/receipt-accept-cases.test.sh`); each case holds the verdict and reason the shell rules gave before they moved to policy. It skips without `opa` and Go. `RECORD=1 bash <test>` re-records the cases of `checks-lint-cases`, `gate-matrix` or `receipt-accept-cases`, only after a deliberate rule change.
