# Ticket stage rule and moments

Ticket stage rule and moments: run `done-done run ticket-stage` (`bash journeys/ticket-stage.sh`, which runs `tests/jg-beads-ticket-stage.test.sh` on a real Beads store with `bd` and `dolt` from the path, or from `JG_BEADS_TEST_BD` and `JG_BEADS_TEST_DOLT`); on a real store `jg-backlog.sh ticket-stage` prints the stage, sub-state and health of a fixture row for every row of the rule table of the state-machine plan (held while building, reclaimed then held, a pull request's merge open and closed, a local landing that publishes nothing, a release opened before the homes moved, a rebase conflict, a return, a revert, a bypass, a pin-back), each also read by jg-q1b3n's rule and the two agree except for the rows that start a new try; `jg-backlog.sh moment` writes the six new moments as an event first and then a UTC RFC3339 string on the row, never moves one back, and `jg-backlog.sh wait` writes the three wait keys in one update with no child row, no stage word and no `hold_kind`; `jg-backlog.sh ticket-drift` prints one drift line (health `lost`) for a landed commit with no `landed_at` and, with `--forge`, for a merged pull request on an open row, and none for a row that agrees; `jg-backlog.sh times` prints a fixture row's ready, landed, live and released times in that order and nothing, with exit 0, for a row with none; the run prints the seconds of one write, under 1 s.
