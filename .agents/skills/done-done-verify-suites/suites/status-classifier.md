# Status classifier (Go)

Status classifier (Go): run `bash tests/jg-classify-go.test.sh` (or `done-done run -- bash tests/jg-classify-go.test.sh` with the suite's log written into `$DONE_DONE_EVIDENCE_ROOT`); it sources `bin/jg-classify-lib.sh`, which forwards to `core/classify`, and proves captain relevance, declared waits, paused-until, the latest-event read, that a done carrying a key closes that key's decision on a squad_lead lane while a keyless one closes nothing, and that a classifier that cannot run exits 2 rather than answering. For a port or change of the grammar, replay the previous reader against the Go command over a home's recorded status lines (`core/classify/README.md` names the replay and its control run); a lab drain of a copied real status file shows `bin/jg-wake-drain.sh` classifying through the Go path.
