# Model statistics

Model statistics: run `JG_BEADS_TEST_BD=$(which bd) JG_BEADS_TEST_DOLT=$(which dolt) done-done run model-stats` (which runs `tests/jg-model-stats.test.sh`) to drive the real `bin/jg-model-stats.sh` over two fixture homes, each with its own real Beads store holding tickets that the spawn's own `claim` and `handoff` events started, that were landed, given a pull request and closed. It proves `jg-backlog.sh times --json --since` lists one fact per ticket with its launches in order, the per-model table (finished, merged, merge rate, time to merge, first pass, rework, switches, started) comes from the tickets of both homes with the sampled lane ledger as the disclosed fallback, a home with no store is named in the limitations without failing the reader, and neither copy of the outcome recorder nor the teardown call remains (screen: none).
