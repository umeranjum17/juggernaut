# Model statistics

Model statistics: run `done-done run model-stats` (which runs `tests/jg-model-stats.test.sh`) to drive the real `bin/jg-model-stats.sh` over two fixture homes, each with its own tickets tables holding tickets started the way the spawn starts them (a start naming the tool, model and effort, and a handover start for each relaunch), that were landed, given a pull request and closed. It proves `jg-backlog.sh times --json --since` lists one fact per ticket with its launches in order, the per-model table (finished, merged, merge rate, time to merge, first pass, rework, switches, started) comes from the tickets of both homes with the sampled lane ledger as the disclosed fallback, a home with no tickets tables is named in the limitations without failing the reader, and neither copy of the outcome recorder nor the teardown call remains (screen: none).
