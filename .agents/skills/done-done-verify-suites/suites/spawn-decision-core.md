# Spawn decision core (Go)

Spawn decision core (Go): run `bash tests/jg-spawn-core.test.sh` (or `done-done run -- bash tests/jg-spawn-core.test.sh` with the suite's log written into `$DONE_DONE_EVIDENCE_ROOT`); it drives `bin/jg-spawn-core.sh`, which `bin/jg-spawn.sh` calls for the harness launch flags (model, effort per harness) and the brief-versus-flags delivery checks, and for the argument grammar and the refusals that need only the arguments (`jg-spawn-core.sh intake`), and proves the flag text, each refusal and notice, the parsed variables, the Claude, Rovo and OpenCode grants, the home token and per-launch OpenCode store, the launch-env allow-list, credential strip and `env -i` wrap, the per-adapter launch templates (`launch-template`), the squad_lead home and worktree isolation checks (`home-validate`, `worktree-isolated`), and that a core that cannot run exits 2 rather than answering. For a port or change of those rules, replay the previous shell against the Go command over a home's recorded briefs and task records (`core/spawn/README.md` names the replay and its control run); `bash tests/jg-spawn-dispatch-profile.test.sh` then shows a real spawn launching through it.

Lease identity: `bash journeys/spawn-clone-identity.sh` drives the real spawn with fixture pool copies from matching and different clones.
It proves the matching copy launches and the foreign copy is refused with both Git common directories while its lease and dirty contents remain.
