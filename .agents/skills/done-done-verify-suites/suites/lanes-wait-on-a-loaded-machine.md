# Lanes wait on a loaded machine

Lanes wait on a loaded machine: run `done-done run spawn-load-admission` with `JG_BEADS_TEST_BD` and `JG_BEADS_TEST_DOLT` naming the pinned builds; the real `bin/jg-spawn.sh` over a fixture home whose load history (the load alarm's record in `bin/jg-reaper-lib.sh`) has stayed above `config/reaper-load-factor` times the cores for `config/reaper-load-minutes` defers a fresh ship with exit 75 and one `deferred:` line naming the load, writes no task record, keeps its backlog item queued and leaves the running lane's record unchanged; the same lane launches once the load is back under the limit, the window and the factor come from config, `config/reaper-off` defers nothing, and a lead home is deferred by its main home's history (`tests/jg-spawn-load-admission.test.sh`); the run writes its log and `steps.json` (screen: none).
