# Landing, go-live and day-summary Evidence cards

Landing, go-live and day-summary Evidence cards: run `done-done run landing-card` (`bash journeys/landing-card.sh`: this test, then `tests/jg-trunk.test.sh` for the lander's gate figures; logs `landing-card.log` and `jg-trunk-test.log`, and `steps.json`); over a fixture home and the real sign-off-axi on a temp board, every landing row gets one `landing-<commit>` card with the gate's scripts run, failed on the first run and seconds (`not recorded` when the proofs row has none), a home with no `data/landing-card-since` marker gets one `landings-<day>` summary per old day and no per-landing card for old rows while a landing after the marker gets its own, every `live*` row of trunk-in-use.tsv gets one `live-<commit>` card listing the landings since the previous live commit with the delivery machine's word only for registered lanes (a failed or per-home row gets none), `landing-card.sh summary <home> <day>` posts one `landings-<day>` card once, and a second run posts nothing (screen: none).
