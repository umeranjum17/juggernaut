# Trunk returns: a conflict and a moved trunk are reproduced, and a baseline counts the returns by cause

Trunk returns: run `bash tests/jg-trunk-base-movement.test.sh` (the `trunk-landing` journey runs it too); the real `core/trunk-landing/trunk-landing.sh check` and `bin/jg-trunk.sh land` run over real git repositories with a gate that holds one lane while other lanes land. It proves a lane gated while another lands conflicts and is returned with its path after one gate run, a lane moved under three times is gated three times and returned as "the trunk kept moving", a lane moved under once lands after one extra gate run, and `core/trunk-landing/returns-baseline.sh <home> [--heads]` reads the attempt records those landings left and prints the returns split by cause (conflict, trunk-moved, gate-failure, other) and by source head, with no return for a lane that landed, and refuses a home with no records (screen: none).
