# Bypass says so

Bypass says so: run `done-done run bypass-says-so` (`bash tests/jg-bypass-says-so.test.sh`, which writes its log into the run's folder); it calls the real `bin/jg-pr-check.sh`, `bin/jg-trunk.sh release`, `bin/jg-live-claim.sh` and `bin/jg-beads-view.py` in a fixture home: the pull request of a bypassed ticket gets a green `juggernaut/proof` status reading "bypassed: no proof ran (word <id>)" and an ordinary ticket gets none, a release of three tickets with one bypassed lists that one in its body, the live-claim check prints "not proven: bypassed by the owner" for the bypassed ticket only (a hand-written record is not believed), and the board card shows `unproved: yes`; it reads only generated fixtures (screen: none).
