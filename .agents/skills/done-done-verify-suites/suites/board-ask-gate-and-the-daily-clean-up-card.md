# Board ask gate and the daily clean-up card

Board ask gate and the daily clean-up card: run `bash tests/jg-board-gate.test.sh` for the gate (a non-must ask is routed once and dismissed with the one of sign-off-axi's three reasons that fits (replaced, done-elsewhere, else not-relevant), a key or title with a question mark or slash still makes a valid slugged tag file, one card is one ask however many lines its detail holds, an unchanged set of offending keys alerts once while an addition to it alerts again, and a hold's card is dismissed as done-elsewhere once its hold is answered, released or closed while an open hold's card stays, a `must: plan-approval` or `must: release-word` card is posted and counted while a made-up category is still refused, an ask whose ticket is done, that a later answered card superseded, or that is past its time to live is withdrawn with a row in `data/board-withdrawn.tsv` while an owner call never expires, and on the Ask me first leash no ask is dismissed), and `JG_TEST_FORK=<checkout> bash core/tickets-sync/tests/cleanup-report-card.test.sh` for the clean-up against the real sign-off-axi (a report card that takes no answer, its findings on it and every finding in its report file, the gate neither counting nor routing it, and the day's key already taken by the old keep/remove ask sending the report on beside it).
Live read-only: `sign-off-axi list <board> --json | jq -r '.items[]? | select(.key|startswith("ticket-cleanup-")) | .kind'` on a home's board prints `report`, and `JG_HOME=<home> bin/jg-board-gate.sh waiting` counts no clean-up card.
