# Report writer

Report writer: run `done-done run report-writer` (`bash core/report-writer/run-proof.sh`); the host table over a stand-in agy (model pin, path scrub, rewrite, refusals, lint rules, page), then one real sitrep written from the live bearings snapshot by the real agy and Gemini 4 Neon, linted, rendered and captured at 390 px (PNG screen, page width and text with no local path). Set `JG_MAIN_HOME` to the home to read.
