# Plan gate

Plan gate: run `done-done run plan-gate` (`bash journeys/plan-gate.sh`, which runs `tests/jg-plan-gate.test.sh` and writes the log and the step record into the run's folder); it calls the real `bin/jg-plan-gate.sh` and `core/plan-gate/check.sh` from a fixture Main home and a registered Squad Lead home, both on real Beads stores: a lead's row gated on a row of Main's store is not ready, one tick of the check closes the gate once Main's row closes and the row is ready, a tool gate opens when the tool reports the version, and a plan's approval writes the dispatch approval record on each slice of the file in its owner's home and on no other row; it reads only generated fixtures (screen: none). It needs `JG_BEADS_TEST_BD` and `JG_BEADS_TEST_DOLT`, and skips without them.
