# Planned wait honoured end to end

Planned wait honoured end to end: run `done-done run planned-wait` (`bash tests/jg-planned-wait.test.sh`); real watcher and drain cycles over a disposable home prove a `paused:` or `blocked:` wait that names a clearing time with `until <UTC time>` (a change held for the next release branch) raises no wake and no stale alert before that time, while a blocked wait that names no clearing condition, and a planned wait whose time has passed, still climb to the owner and then Main. A working or paused line that states the same `[key=]` after a blocked line drops the armed wait, so only an unchanged blocker escalates. It fails on the unmodified tree, where the blocked planned wait wakes at once (screen: none).
