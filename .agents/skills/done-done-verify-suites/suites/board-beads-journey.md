# Board Beads journey

Board Beads journey: run `JG_BEADS_TEST_BD=$(which bd) JG_BEADS_TEST_DOLT=$(which dolt) JG_SIGN_OFF_DIR=<built sign-off checkout> done-done run -- bash tests/jg-board-beads-journey.test.sh` to start the sign-off board with `SIGN_OFF_TICKETS_ADAPTER` set to `bin/jg-ticket-adapter.py` on a throwaway embedded Beads store; it proves the board lists the same open tickets as `bd list`, each ticket's page shows id, status, assignee and parent as `bd` gives them, the board adds no key of its own and no stage, and a closed ticket is left out of the list, with the list and a ticket page captured at 390 px (mobile emulation) and 1280 px (screen: Tickets list and a ticket page, look at both widths).
