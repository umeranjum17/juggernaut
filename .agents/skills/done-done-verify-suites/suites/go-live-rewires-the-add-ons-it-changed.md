# Go-live rewires the add-ons it changed

Go-live rewires the add-ons it changed: run `done-done run -- bash -c 'bash tests/jg-update-local-base.test.sh && bash tests/jg-host-wiring.test.sh'` (screen: none); a fixture trunk carries the real `bin/jg-host-wiring.sh` and the real `core/tickets-sync`, every other step a logging stub, and `bin/jg-update.sh --base` moves a lead and Main in a throwaway user home: the first move wires every step and records `state/host-wiring.tsv`, a move that changes `core/tickets-sync/sync.py` wires only tickets-sync and its installed copy equals `core/`, a move that changes no add-on file runs no wiring, a failing step is named in the row as `live,wiring-failed:<step>` and retried on the next move, and a home whose health check rolls it back onto the moved commit is still wired to the code it holds.
