# Go-live rewires the add-ons it changed

Go-live rewires the add-ons it changed: run `done-done run -- bash -c 'bash tests/jg-update-local-base.test.sh && bash tests/jg-host-wiring.test.sh && bash tests/jg-trunk-live-home.test.sh && bash core/pipeline-quota-failover/tests/pipeline-quota-failover-uninstall.test.sh && bash core/claude-accounts/tests/claude-accounts-pick.test.sh && bash tests/jg-home-guard.test.sh && bash tests/jg-trunk.test.sh'` (screen: none); a fixture trunk carries the real `bin/jg-host-wiring.sh` and the real `core/tickets-sync`, every other step a logging stub, and `bin/jg-update.sh --base` moves a lead and Main in a throwaway user home: the first move wires every step and records `state/host-wiring.tsv`, a move that changes `core/tickets-sync/sync.py` wires only tickets-sync, whose checks run that home's own `core/`, a move that changes no add-on file runs no wiring, a failing step is named in the row as `live,wiring-failed:<step>` and retried on the next move, and a home whose health check rolls it back onto the moved commit is still wired to the code it holds.
A host copy a step installed that is edited or deleted after the step wired is drift whatever git says: in a committed fixture home on a throw-away host `bin/jg-host-wiring.sh --drift` names it (`<step>`, copy, `differs` or `missing`, source), `--changed` reruns exactly that step and the copy equals its source again, and the next run reruns no step that wired; `bin/jg-trunk-live-home.sh` runs the moved checkout's `--changed` for the home, and a failed step is its failure with the steps named while the home stays at the moved-to commit.
A pipeline config that names the pre-rename `fm-pipeline-quota-failover` wrapper is moved to the current wrapper by the real step and every home ends `live`, a rerun changes nothing and a foreign wrapper is still refused; an account-pool file naming the pre-rename add-on chooser is adopted the same way.
A home whose shared reference-transaction hook is the trunk guard moves and stays `live`, because the home guard chains the trunk guard (both still refuse, a rerun and a landing change neither hook); any other hook refuses the guard install and the `rolled-back:missing-guard` row names that refusal.
