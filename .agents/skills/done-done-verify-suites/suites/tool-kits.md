# Tool kits

Tool kits: run `done-done run tool-kit` (`bash journeys/tool-kit.sh`), which runs every kit's `journey.sh` and `asks.txt` found under `core/tool-kits/kits/`; the takeone kit makes a real `takeone motion --no-ai` film, posts it to a throwaway board, saves the receipt and runs `jg-tool-kit.sh check` to PASS, then breaks the film, the record, the take, the card, the receipt, the report, the board, the kit name, the kit folder and the check and sees exit 1 with each reason; two fixture kits prove a named kit wins, build words win and two matches give no kit. `done-done run tool-kit-spend` (`bash journeys/tool-kit-spend.sh`) runs every kit's `journey-spend.sh`; it skips with `skipped: needs spend approval` unless it is given `--approved`, and its registry entry (the only place that passes `--approved`) has a `spends` line, so done-done parks it until approved; `tool-kit` proves the skip on a fixture kit that only writes a marker. Inspect the run-owned `tool-kit-transcript.txt`, `takeone-journey-transcript.txt`, `takeone-journey-film.mp4`, `takeone-journey-receipt.json` and `takeone-journey-card.json` (screen: none).
