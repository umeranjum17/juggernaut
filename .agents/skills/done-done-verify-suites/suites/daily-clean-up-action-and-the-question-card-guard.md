# Daily clean-up action and the question-card guard

Daily clean-up action and the question-card guard: run `done-done run tickets-cleanup-acts` (it runs both tests below, then drives the clean-up on a throwaway home and saves the tickets before and after, the closed ticket's note, the report file and the question card), or run `JG_TEST_FORK=<checkout> bash core/tickets-sync/tests/cleanup-acts.test.sh` (real jg-backlog.sh on a Beads store and sign-off-axi, gh-axi stood in for GitHub: a closed-unmerged, duplicate and superseded ticket is closed with its reason in its note, while a captain ask, a captain hold, a design pick and work in flight stay open, and it fails when the clean-up only flags again) and `JG_TEST_FORK=<checkout> bash core/tickets-sync/tests/cleanup-keeps-question.test.sh` (a question card whose changes are all closed unmerged is never dismissed on its own link, its done ticket or its done task, while a card whose change merged still is archived).
