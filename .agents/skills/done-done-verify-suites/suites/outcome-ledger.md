# Outcome ledger rebuilds from the trunk records

Outcome ledger: run `done-done run jg-outcome-ledger` (`bash journeys/outcome-ledger.sh` runs `tests/jg-outcome-ledger.test.sh` and writes its log, the ledger rows `ledger.tsv` and `steps.json` into `$DONE_DONE_EVIDENCE_ROOT`); the real `bin/jg-outcome-ledger.sh build` reads a fixture home's landings, proofs, in-use, release and version records, its bypass records and its git clone, and prints one dated row per ticket and stage. It shows a full life (built, landed, in-use, released), a release that is only raised (release-raised, never released), a bypass (bypass in the proof and bypass columns, and bypass-unverified for a record no bypass row backs), a revert (a reverted row, and the flag reverted on every row of the undone commit, the revert commit being no landing), a duplicate landing (one row flagged duplicate with no later stage) and a landing with no proofs row (none-recorded, no built row). Each row carries an owner class from recorded words and waivers only (bypass, captain-word, standing-waiver, none, or unknown when no record names the ticket), and `jg-outcome-ledger.sh publications` prints one timing row per release publication (due, attempt, open, merged, minutes, path automatic or fallback, written by `jg-trunk.sh` into `data/trunk-publications.tsv` and proved through the real publish and release in `tests/jg-trunk-publish.test.sh`). A rerun prints the same rows, and a missing source record is named on stderr with exit 2 while the other records still print The same journey then runs the real `bin/jg-ledger-reconcile.sh` (`tests/jg-ledger-reconcile.test.sh`, report saved as `reconcile.md`) on a fixture home with two releases: every commit of a release lands in one class (landed, revert, revert-unrecorded, rebased-copy, merge, pre-ledger) and the classes add up to the git total, a landing outside the releases reads superseded-sha or after-last-release, a stray commit no record explains is printed as unexplained and the command exits 1, the same fixture without it exits 0, and a missing source record exits 2 (screen: none).
