# Outcome ledger rebuilds from the trunk records

Outcome ledger: run `done-done run jg-outcome-ledger` (`bash journeys/outcome-ledger.sh` runs `tests/jg-outcome-ledger.test.sh` and writes its log, the ledger rows `ledger.tsv` and `steps.json` into `$DONE_DONE_EVIDENCE_ROOT`); the real `bin/jg-outcome-ledger.sh build` reads a fixture home's landings, proofs, in-use, release and version records, its bypass records and its git clone, and prints one dated row per ticket and stage. It shows a full life (built, landed, in-use, released), a release that is only raised (release-raised, never released), a bypass (bypass in the proof and bypass columns, and bypass-unverified for a record no bypass row backs), a revert (a reverted row, and the flag reverted on every row of the undone commit, the revert commit being no landing), a duplicate landing (one row flagged duplicate with no later stage) and a landing with no proofs row (none-recorded, no built row). A rerun prints the same rows, and a missing source record is named on stderr with exit 2 while the other records still print (screen: none).
