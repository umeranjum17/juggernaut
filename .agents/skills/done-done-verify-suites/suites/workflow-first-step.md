# Approved workflow steps always have a runnable first step

Workflow first step: run `done-done run jg-workflow-kinds` (`bash tests/jg-workflow-kinds.test.sh` writes its log into `$DONE_DONE_EVIDENCE_ROOT`); the real `bin/jg-workflow.sh advance` runs the shipped `worker`, `recon` and `owner` kinds over a scratch home with the real `bin/jg-brief.sh` and `approve-dispatch`. The log shows a plain ship getting a complete brief and a worker-route approval once, a report-only Recon closing on its report and building nothing, a build after a Recon waiting for the owner's yes and then naming the approved report, a kind with no handler raising one named alert, and an unregistered delivery mode failing once with no approval written. The owner's hold and the project registry are stand-ins (screen: none).
