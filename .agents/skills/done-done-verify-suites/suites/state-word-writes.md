# State word writes

State word writes: run `done-done run state-write` (which runs `tests/jg-state-write.test.sh`, then `bin/jg-state-lint.sh --check` on the repository, and writes its log and `steps.json` into the run's folder); in a test home, the real `bin/jg-machine.sh write ticket landed <file>` exits 1, lists the legal ticket values and leaves the file as it was, a legal value is written, `bin/jg-move.sh` writes no line when the table's move lands outside the enum, and `bin/jg-state-lint.sh` prints the count of bare state strings (today's count is the number in `core/machines/bare-states.baseline`) and exits 1 on a fixture that adds one; it reads only generated fixtures (screen: none).
