# Plain ticket names

Plain ticket names: run `done-done run plain-ticket-names` (`bash core/tickets-sync/run-rename-proof.sh && bash tests/jg-retitle.test.sh`) with `JG_BEADS_BD`, `JG_BEADS_DOLT`, `JG_BEADS_TEST_BD` and `JG_BEADS_TEST_DOLT` naming the pinned builds. On a real Beads store `jg-backlog.sh add` refuses a title that starts with a plan code (J20d-3, S18c, mf-m2, TC4b), with or without a leading type tag, names the code and files nothing; `bin/jg-retitle.py list` names the open tickets whose title is not plain words, `apply` stops the whole pass when one new title fails the same rule, a dry run writes nothing, and `apply --write` renames them while the plan code and the earlier title move into the body, so a second pass changes nothing. Five coded tickets renamed that way show on the real sign-off Tickets page at 390 px as five plain titles under their parent ticket (inspect `tickets-390.png`, `tickets-390.txt`, `tickets.json` and `rename.out`; it fails when a plan code still shows). The board's own `JUG-n` key is made by the sign-off board adapter and is not part of this suite.
