# Ticket table fields

Ticket table fields: run `JG_BEADS_TEST_BD=$(which bd) JG_BEADS_TEST_DOLT=$(which dolt) done-done run -- bash journeys/ticket-table-fields.sh` (it runs `tests/item-store-tickets.test.sh` and saves its log and `steps.json`) to drive the real `core/item-store/adapters/tickets.py` on a throwaway item store; an export with every field Beads prints (`created_by`, `updated_at`, `started_at`, `comments`, `events`, `provenance`) imports into the `ticket`, `comment` and `ticket_event` tables and `compare` against that export gives 0 differences, `comment_count` is derived from the `comment` rows, `compare` names a drifted field or a lost comment and a second import repairs it, a plain Beads export with no events or provenance leaves the copy's events and provenance alone, and a store made from an older `tickets.sql` is rebuilt from its log keeping every ticket, link and log row (screen: none).
