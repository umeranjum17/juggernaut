# Backlog hierarchy

Backlog hierarchy: run `JG_TEST_FORK=<Juggernaut checkout> done-done run owner-rules-hierarchy` to drive the real `jg-brief.sh` with a disposable backlog and installed owner-rules feature; it proves parent refusals, existing-parent and upkeep acceptance, captain-ask roots, scout and squad lead exemptions, and tree output for chains, missing ids and cycles.
Run the [sign-off hold journey](sign-off-hold-card.md) to prove raw backlog titles never become cards.
For authorized live cleanup, open a done-done run, use `chrome-devtools-axi` to capture the same Decide board before/after supported `sign-off-axi` commands, inspect both shots, and retain the per-card reasons; never synthesize an owner answer.
Slices are real children: run `done-done run -- bash tests/jg-beads-parent.test.sh` to file an ask, a slice and a piece with `add --parent` on a throwaway home's tickets tables; it proves the store's child ids, the two inherited labels, the epic parent, the refused fourth level and own ids, the tree reading the parent from the edge, and a slice that cannot close while a piece is open (refused with the piece named, closed after it, counted by `epic status`).
A move keeps its filer, its link, its log and its questions: `done-done run -- bash tests/jg-backlog-handoff-move.test.sh` binds a lead home to a main home's tickets tables, with no Beads tool.
It proves each home files under its own name (`main`, `lead:<id>`), `provenance log` of a ticket with no log answers `[]`, and `delete --force` drops tickets, their questions and the edges to them and marks each mention as `[deleted:<id>]`.
Then the real `jg-backlog-handoff.sh` moves a slice: its `parent` is `external:main:<id>` and the ask tracks it, its provenance log is the old one plus one `handoff` event, an open and an answered gate arrive (the answer with the owner's words), `jg-backlog.sh tree --homes` prints one tree, and a repeated take records nothing twice.
