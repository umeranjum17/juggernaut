# The wait word replaces the three meanings of paused

The wait word: run `done-done run wait-word` (which runs `bash tests/jg-wait-word.test.sh`, on a real Beads store with `bd` and `dolt` from the path or from `JG_BEADS_TEST_BD` and `JG_BEADS_TEST_DOLT`); the real status command a brief gives a worker (`bin/jg-lavish-guard.sh --append`) refuses a `paused` line with no wait, a wait with no reason, a word outside the closed lists and the placeholder date 2026-12-31, names the new form `paused [at=<epoch>] [wait=<who>] [reason=<word>]` in the refusal and writes nothing; `jg-backlog.sh hold` writes the three wait keys in the same update (a parked hold waits on `lead` for `parked` and keeps `hold_kind` `parked`, an owner question waits on `owner` for a `decision`, a hold to a date waits on `outside` for the `date`) and `unhold` ends the wait; the quiet rule keys on reason `parked`; and a scaffolded ship brief holds one rule for waiting (screen: none).
