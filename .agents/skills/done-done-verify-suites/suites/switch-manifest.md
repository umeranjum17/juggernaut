# Switch manifest

Switch manifest: run `done-done run switch-manifest` (`bash tests/jg-switch.test.sh`, its log written into the run's folder); on a fixture home with one manifest row of each kind off, `bin/jg-switch.sh status` prints one `off` line each with its reason and who and the seeded detector lines, prints none once each is on, `verify` exits 1 until every row is on, `apply` of an owner row is refused without `--owner-word`, and a policy `apply` appends `key@project=<value>` that `jg_trunk_policy` reads; a hanging check reads `timeout`; the npm kind reads `below-pin`, then `behind-release` from the cache `refresh-releases` writes (a missing, failed or 48-hour-old cache reads `unknown-release`, printed as `unknown` and never counted); `bin/jg-switch.sh flags <project>` prints each flag the fixture project has set (a `gate-lint@project` policy line, `+yolo`, a waiver line, a standing project bypass) with its value, its default and its flip command, and `no flags set` for a bare home; it reads only the fixture (screen: none).

Go-live verifies per home: `done-done run -- bash -c 'bash tests/jg-switch.test.sh && bash tests/jg-update-local-base.test.sh && bash tests/jg-trunk-live.test.sh'` (screen: none); `bin/jg-switch.sh count --home <dir> <change-id>...` prints `switches-off:<n> detectors:<m>`, a fleet move appends `,switches-off:<n>[,detectors:<m>]` to each moved home's row after its wiring (policy `switch-apply` `off|report|auto`, default `report`), and the go-live lines say `In homes` with the home count only when a switch a change in the range declared is off in some home, `In use` otherwise, with a separate `detectors: <m>` line when m is above 0.
