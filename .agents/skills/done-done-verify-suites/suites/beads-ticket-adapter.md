# Beads ticket adapter

Ticket adapter: run `done-done run -- bash tests/jg-ticket-adapter.test.sh` (it copies its output and both conformance logs into done-done's evidence folder) to drive the real `bin/jg-ticket-adapter.py` the way the board does, one JSON request per call, on a throwaway home's tickets tables; it proves the single-home interface returns the row as the tables hold it and leaves closed rows out; over a main home and a local lead home it reads each home with one query, hands a client that names no page size the whole fleet in one page, gives a ticket the same rev from the list and from a get, and derives the four board columns from gates, worker records, ready rows and recent closes, shows each project, routes edits to their store, paginates and reports a home whose tables cannot be read, an update is a patch that keeps a label written beside it and the extra keys it does not name, a write made by hand gives a conflict, a repeated op_id writes once and a reused op_id is refused, history names the actor and the changed fields with the comment in order, and an unreadable store is an error and never an empty list; it also runs the vendored interface conformance script unmodified (16 of 18: check 2 reads the sorted key order of extra, and check 18 needs a list read in part, which the tables never give) and through its documented order-insensitive exception (17 of 18) (screen: none).
