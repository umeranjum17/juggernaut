# Beads ticket adapter

Beads ticket adapter: run `JG_BEADS_TEST_BD=$(which bd) JG_BEADS_TEST_DOLT=$(which dolt) done-done run -- bash tests/jg-ticket-adapter.test.sh` (it copies its output and both conformance logs into done-done's evidence folder) to drive the real `bin/jg-ticket-adapter.py` the way the board does, one JSON request per call, on a throwaway embedded Beads store; it proves a ticket is bd's own row (id, status, assignee and parent as `bd show` gives them, no invented field), a list leaves closed rows out, an update is a patch that keeps a label bd alone wrote, a write made by hand gives a conflict, a repeated op_id writes once and a reused op_id is refused, history names the actor and the changed fields with the comment in order, and an unreadable store is an error and never an empty list; it also runs the vendored interface conformance script unmodified (17 of 18, check 2 reads bd-sorted key order) and through its documented order-insensitive exception (18 of 18) (screen: none).
