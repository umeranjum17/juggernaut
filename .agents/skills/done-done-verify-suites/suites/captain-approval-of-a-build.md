# Captain approval of a build

Captain approval of a build: run `done-done run -- bash tests/jg-captain-approval.test.sh`; over a fixture home with a markdown backlog it proves `bin/jg-spawn.sh` and the `[order]`/`[route]` path of `bin/jg-send.sh` refuse a build of a `[captain-ask]` or Recon-born ticket until its body carries the signed `approved-by-captain:` line, that `bin/jg-captain-hold.sh answer` and `bin/jg-inbox.sh approve` (chat notes only) write that line, that a hand-written or copied line is refused, and that a Recon spawn or `kind=recon` order is never gated. No model is called.
