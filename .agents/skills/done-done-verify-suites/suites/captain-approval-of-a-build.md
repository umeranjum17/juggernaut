# Captain approval of a build

Captain approval of a build: run `done-done run -- bash tests/jg-captain-approval.test.sh`; over a fixture home with a markdown backlog it proves `bin/jg-spawn.sh` and the `[order]`/`[route]` path of `bin/jg-send.sh` refuse a build of a `[captain-ask]` or Recon/plan-born ticket until one record of the captain's yes exists, and that the start names that record: the signed `approved-by-captain:` line, which `bin/jg-captain-hold.sh answer` and `bin/jg-inbox.sh approve` (chat notes only) write; an `owner-words: note:<id> "<his words>"` line whose words are whole words of his own chat note (in a Squad Lead home, the parent home's note); or, for a Recon/plan-born slice, its `parent:` report's record. It also proves that a hand-written or copied line, words not in the note, a non-chat note, an unanswered parent and a `[captain-ask]` ticket that only names a parent are refused, and that a Recon spawn or `kind=recon` order is never gated. A dotted ticket (`jg-x.7`, task `jg-x-7`) is read by its ticket id: refused unsigned, spawned once his yes is recorded. No model is called.
