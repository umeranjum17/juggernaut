# Skipped script is not green: a required script that failed and then only skipped on its rerun leaves the verify incomplete

Run `done-done run -- bash -c 'set -e; bash tests/jg-trunk-gate.test.sh > "$DONE_DONE_EVIDENCE_ROOT/trunk-gate.log" 2>&1'`; over a fixture home with real git and the real `bin/jg-trunk.sh verify`, its case `a script that skips on its rerun is incomplete, never green` proves that a script that fails on the verify's first run and ends its rerun with exit 0 and `gate_skip=true` is not set aside as flaky and not counted as passed: the verify exits non-zero, says the gate is incomplete and names the script, leaves the green pin where it was, reverts and charges nothing and files no flaky row, while a script that really passes on its rerun is still judged flaky and the verify goes green and moves the pin (screen: none).
