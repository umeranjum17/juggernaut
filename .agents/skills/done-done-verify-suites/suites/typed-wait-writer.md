# One writer for typed waits

The typed wait writer: run `done-done run typed-wait-writer` (which runs `bash tests/jg-wait-write.test.sh` on the homes' tickets tables); in two isolated homes the real writer (`bin/jg-wait-write.sh`, the one writer `jg wait`, `jg ask` and the answer path of `bin/jg-send.sh` share) opens an owner call and a worker question, a done and a failed close the worker's own question and never the owner call, the real answer (`bin/jg-send.sh --resolve-key`) to a busy worker closes the call in its own home only, the answer waits durably in the worker's inbox across busy to idle, a second resolution by the writer or by the answer path writes nothing and names the wait as already resolved, a wait opens once as written, a new question on an open key replaces the old one, and a word outside the closed lists writes nothing (screen: none).
