# Ports and adapters guard

Ports and adapters guard: run `done-done run ports-adapter-refusal` (full cases: `bash tests/jg-ports-check.test.sh`); a clone of the checkout runs the real guard and proves a change importing the Pi engine kit or running the message bus client outside its adapter is refused naming the file, one inside the adapter passes, a change cannot add itself to the legacy list, a plan naming a dependency must name its port and adapter, and the real tree has no unlisted client use.
