A green commit reaches every home and one bad home does not stop the others: run `done-done run -- bash -c 'bash tests/jg-update-local-base.test.sh && bash tests/jg-home-health.test.sh && bash tests/jg-trunk-live-home.test.sh'` (screen: none); a fixture fleet of three leads and Main moves to a trunk tip with the real `bin/jg-update.sh --base`, the real `bin/jg-home-health.sh` and the real lead-sweep wiring: a lead whose launch overlay lacks a hook is refreshed and goes `live`, a lead whose watcher beacon was stale before and after the move stays on the commit with the row `live,pre-existing:stale-beacon` and one report line, every home has `state/lead-sweep.check.sh`, and the move ends clean.
A second fleet where one lead's supervision read fails on the new commit only and another lead is dirty: the first is pinned back (`rolled-back:slow-session-start`), the dirty one is `skipped:dirty`, the other leads and Main are `live` (the rollout goes on past both), the last line names the two homes left, and the next run takes both once they are clean.
`check --all` lists every failed fact of a home before a move and `check --before` carries a fault the home already had, never `missing-guard` or `not-at-base`.
