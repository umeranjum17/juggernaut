# Machine services belong to Main

Machine services belong to Main: run `done-done run unit-claim` (`bash journeys/unit-claim.sh`, which runs `tests/jg-unit-claim.test.sh` and writes its log and `steps.json` into the run's folder); in a throwaway HOME with a lab `systemctl` that reads each unit's own `Environment=` line, it proves a real session start in a home whose four units (`jg-sentinel`, `jg-wake-engine`, `jg-wake-watcher`, `jg-router`) serve another home claims all four and shows them serving this home, that a second start claims nothing, that `bin/jg-unit-claim.sh status` names a unit that is installed but not running and one that serves another home while a unit that is absent or serves here stays quiet (that line is the watcher's 30 s check wake, `bin/jg-watch.sh` `run_fast_checks`), that a Squad Lead home is refused by `claim`, by `bin/jg-sentinel.sh unit` and by `bin/jg-stack.sh up` with one reason and gets no banner line or move command, and that a checkout that is not the home's own copy neither reads, reports nor moves the units. The real user manager is never read or changed (screen: none).
