# Gate quarantine

A quarantined test script can never hold a landing: run `done-done run gate-quarantine` (journey `journeys/gate-quarantine.sh`, screen: none); the real `bin/jg-test-run.sh --required-shards` runs over a clone whose lane changes `tests/jg-trunk-verify.test.sh`, which `tests/gate-quarantine.tsv` lists and which would fail if it ran: the gate prints `JG_TEST_QUARANTINED <script> reason=<why>`, never runs the script, counts no test and exits 0, while the control lane with the line removed runs the script and fails the gate. The log is `gate-quarantine.log` in the run folder; `bash tests/jg-test-run.test.sh` holds the same case over a throwaway repository. `--all` (the on-demand verify and the release CI) and a script named on the command line still run it.
