# Done-done author route

Run `done-done run -- bash journeys/done-done-author-route.sh` to drive the installed CLI's `doctor --json` in a synthetic Git repository with temporary fleet and done-done homes.
The documented fleet rule selects GPT 6.1 Terra, an explicit Sol-first override selects GPT 6.2 Sol, and removing the fleet rule restores the legacy configured author.
The command captures the three agent rows and the installed CLI version in the run folder.
Both engine paths are inert fixture executables and the probe makes no model calls.
