# Merge-gate install and migration

Merge-gate install and migration: run `bash merge-on-green/tests/merge-on-green.test.sh`; its install cases prove a home moved from the retired `fm-merge-on-green` copy keeps running the gate through the one redirect line left there, its rule file gone, a re-run changing nothing, a home keeping the install share its shim names, and an unknown shim target, a shim for another home, or an unknown retired directory refusing with nothing written. Live, in a task-owned share: point a home's `state/merge-on-green.check.sh` at a seeded retired copy, run `merge-on-green/wiring.sh <home>`, then lint a real pull request with `JG_HOME=<home> <share>/jg-merge-on-green/checks-lint.sh` for both the green and the red case, and restore the home's shim and trust record byte for byte.
