# Post-merge CI under the one rule

Post-merge CI under the one rule: run `done-done run jg-post-merge-ci-main jg-trunk-live` (which run `bash tests/jg-post-merge-ci-main.test.sh` and `bash tests/jg-trunk-live.test.sh` and write `$DONE_DONE_EVIDENCE_ROOT/${RUN_ID}.log`); the real `bin/jg-post-merge-ci.sh --main` over a forge stand-in that serves run lists and timing aggregates and a real git history files one item for a new failure naming the run and the commit that introduced it, updates the open item when a later run fails the same script, files a timeout, a missing baseline or a red run with no failing script as incomplete and never restores it, and pins the homes back through `jg-trunk.sh ci` only with `--restore` and counted failures beyond the grace; the registered check `core/post-merge-ci/check.sh` starts it on its interval, detached and silent; under a go-live waiver the unset quiet window and cap are 0 and a window the home sets wins.
