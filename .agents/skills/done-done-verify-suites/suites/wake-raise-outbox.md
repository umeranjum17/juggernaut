# Wake raise owed to the outbox

Wake raise owed to the outbox: run `done-done run wake-raise-outbox` (`bash journeys/wake-raise-outbox.sh`); in a throwaway home the wake engine cannot run at all, and the production producer in `bin/jg-wake-lib.sh` still answers success with the raise owed in `state/.wake-bus.outbox.jsonl`; then the engine runs but refuses every raise (a corrupt `state/bus/wake-order`), the real `bin/jg-watch.sh` runs one cycle, names the wake it raised, exits 0, and that raise is owed too with the store's own cause on stderr (the same fault exits 1 at the watcher's raise site before this change); finally a throwaway JetStream server and a real build publish the owed rows, the outbox empties, and the read model every other reader opens holds both wakes. `bash tests/jg-wake-queue-live.test.sh` holds the same contract on the shared bus. Live: `JG_HOME=<home> bin/jg-wake-bus-probe.sh` shows a home's outbox size, and `bin/jg-migration-live.sh wake` names the events a home still owes the bus. `bin/jg-wake-bus.sh` owns the raise-or-owe rule, `core/bus/cmd/jg-bus/wakebus.go` owns the exit statuses it answers, and `bin/jg-watch.sh` owns the cycle that never stops for a refused raise.
