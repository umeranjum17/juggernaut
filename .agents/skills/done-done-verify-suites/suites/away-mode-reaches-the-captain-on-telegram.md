# Away mode reaches the captain on Telegram

Away mode reaches the captain on Telegram: run `done-done run -- bash tests/jg-away-reach.test.sh` with the log written into `$DONE_DONE_EVIDENCE_ROOT`; the real `bin/jg-afk-contract.sh enter` arms the watcher check with no further command, the log shows no message before 30 minutes, one update at 30 minutes, none for an unchanged fleet, an urgent message at once for a new needs-decision or sign-in line (secrets removed, an old block ignored), and `archive` disarming it. The test fails if the clock or the urgent path is removed (screen: none).
