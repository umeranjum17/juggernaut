# Teardown process reaping and removal validators (Go)

Teardown process reaping and removal validators (Go): run `bash tests/jg-teardown-core.test.sh`; its `reap`, `validate-removal`, `validate-child` and `validate-home` checks lead a real process out of a directory (TERM, then KILL for one that ignores it), refuse the active home, the repo, an unseeded or mismatched Squad Lead home and a home holding another registered home, and exit 2 on a request that cannot be read. `bash tests/jg-teardown.test.sh` drives the same commands through `bin/jg-teardown.sh`. For a port or change, replay the previous shell functions (cut from the base commit) against the Go command over generated process, lsof, identity and registry situations, with a corrupted control that must differ (`core/teardown/README.md`, "Slices 3 and 4"); `bin/jg-teardown-core.sh reap` with the real `lsof` ends a leaked process, and `validate-removal` on the real home path refuses it.
