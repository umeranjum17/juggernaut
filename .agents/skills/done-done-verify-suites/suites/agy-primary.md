# agy primary Overwatch

agy primary Overwatch: run `done-done run agy-primary` (`bash journeys/agy-primary.sh`, which runs the agy cases of `tests/jg-session-start.test.sh` and `tests/jg-turnend-guard.test.sh`); the tracked `.agents/hooks.json` commands run the way agy runs them, under a real process named agy: the SessionStart command takes the lock as that process and injects a digest naming agy, the Stop command continues an unsupervised turn end once with the agy repair line and stops on either loop signal, and the PreToolUse command denies a backgrounded arm as agy's stdout decision; with `JG_AGY_PRIMARY_LIVE_E2E=1` the journey also runs `tests/jg-agy-primary-live-e2e.test.sh` against the installed agy and keeps its pane and conversation under `live/` (screen: none).
