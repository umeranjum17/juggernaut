# First-draft rule on a lane with several pull requests

First-draft rule on a lane with several pull requests: run `done-done run -- bash tests/jg-design-gate-first-draft.test.sh`; the real `jg_dod_accept_ship_done` runs over real commits and proves the design rule is measured at the head of the pull request the done names (forge head, else recorded `pr_head`) when the copy sits at a later slice with no receipt, while a PR head with no first-draft line or a judge-only receipt is still refused.
