# Pi launch first turn

Pi launch first turn: run `done-done run pi-launch-first-turn` (`bash tests/jg-spawn-pi-first-turn.test.sh`); the real `bin/jg-spawn.sh` over a fixture home and a real git worktree stages the real Pi launch command and arms the real busy record, and a stand-in terminal counts each key.
The run proves a Pi worker launch whose copy is a managed fleet Treehouse pool slot carries `--approve` while the same launch outside the pool carries none, that a Pi without the flag still launches, that a first turn which never starts gets exactly one retried submit and one `worker-stopped` alert naming the task while the lane stays up, and that a first turn whose adapter event arrives is neither retried nor alerted.
The run log is the suite's own report (screen: none).
