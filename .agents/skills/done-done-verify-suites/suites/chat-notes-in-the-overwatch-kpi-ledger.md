# Chat notes in the Overwatch KPI ledger

Chat notes in the Overwatch KPI ledger: run `done-done run -- bash tests/jg-overwatch-kpi.test.sh` and `done-done run -- bash tests/jg-bus-gateway.test.sh` (logs into `$DONE_DONE_EVIDENCE_ROOT`); `TestGatewayIngress` proves an owner's Telegram note adds one `data/overwatch-kpi.jsonl` row carrying its inbox note id, a replay and a dropped update add none, and a home whose `config/overwatch-kpi` reads `off` records nothing; the KPI test proves `record --id` is idempotent and `tag --message <seq|inbox-id>` tags the named message (no argument still tags the newest, an unknown seq or id exits 2) and the scorecard counts that message (screen: none). `done-done run -- bash tests/jg-primary-chat-approval.test.sh` proves a message typed in the locked primary session is filed as the handled note `[chat primary <session>:<seq>]` with his whole words, an order quoting them as `owner-words: note:<id>` is approved by the real reader, and another session, a home with no lock, or machine text files no note; the same test proves an agy primary locked through the real lock files that note from the `PreInvocation` that opens a turn on a typed prompt and none from a background-task wake, a repeat call or another conversation; it also proves a Pi primary files the note, named by a digest of its session file path, when the tracked primary extension forwards a typed prompt, and an injected prompt, another Pi pane or a process that is not Pi files none. `done-done run -- bash tests/jg-lock-pi-session-id.test.sh` proves an agy primary records its conversation id beside the lock while a foreign conversation, a malformed id and a codex that inherited the id are refused (screen: none).
