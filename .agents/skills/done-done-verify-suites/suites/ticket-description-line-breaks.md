# Ticket description line breaks

Ticket description line breaks: run `done-done run -- bash core/tickets-sync/tests/description-linebreaks.test.sh` with the log written into `$DONE_DONE_EVIDENCE_ROOT`; the real installed sync, the Beads backlog and sign-off-axi prove a new board ticket's description equals its task body byte for byte, so `# Ask`, `# Why` and `# Done when` each start a line, and it fails when the lines are joined into one (screen: none).
With `JG_TEST_MERGED_PR=<real merged delivery URL>` and gh-axi available, the same journey also proves a merged PR closes an in-flight task.
For authorized fleet backfill, open a done-done run, run a temporary install against a fixture home whose registry names the real backlog homes, and capture the same owner board Tickets list before/after `sync.py --reconcile` on a task-owned sign-off server, applying authorized supersessions with `--close HOME/ITEM --reason superseded`, and capture the Tickets tab with `chrome-devtools-axi` at 390px in light and dark for a data-only sync change (also 1280px when layout changes); record source counts, repeat writes and read-only backlog hashes, inspect every shot, then seal and judge the run on the pool account.

Long ticket body: run `done-done run -- bash core/tickets-sync/tests/long-body.test.sh` with the log written into `$DONE_DONE_EVIDENCE_ROOT`; the real installed sync, the Beads backlog and sign-off-axi prove a body past the board's 4000-character limit reaches the board trimmed to fit with a "Full ticket: HOME/ITEM" link at its end instead of the ticket being skipped, and a short body stays whole (screen: none).
