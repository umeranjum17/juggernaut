# Links as Beads edges

Links as Beads edges: run `done-done run -- bash tests/jg-beads-native-n5.test.sh` with `JG_BEADS_TEST_BD` and `JG_BEADS_TEST_DOLT` set to the pinned builds and any `skip:` line treated as a failure; it proves migration turns `linked-to:` and `parent:` lines into edges and refuses a line with no edge, that `bin/jg-captain-hold.sh blocking` gives the same exit codes on a file home, an edge-only store and a store of lines after `relink`, that a write and a body edit lay and drop the edge, and that a real cut keeps every answer. No model is called.
