# Design card is a gate

Design card is a gate: run `done-done run design-card-gate` to drive the real `bin/jg-question-card.sh post --must design-pick --raised-by <ticket>` and `bin/jg-board-answers.sh` on the home's tickets tables; the post makes one human gate on the raising ticket with the card key in its metadata and files no `[design-ux]` row, a card naming no raising ticket or an unknown one is refused, a repeat post makes no second gate, the ticket's merge is refused while the gate is open, and the board answer closes the gate with his whole words, leaves the ticket open and lets the merge through. The run writes its log and `steps.json` (screen: none).
