# Delivery style

Delivery style: run `done-done run delivery-style` (`bash journeys/delivery-style.sh`, which runs `tests/jg-delivery-style.test.sh` and writes its log and `steps.json` into the run's folder); it prints the row of each of the four modes from `core/machines/styles/delivery-styles.tsv` through `bin/jg-delivery-style.sh`, refuses an unknown mode, and checks that no row names a prover, prints the local, review and trunk fact of each mode and the count of mode-branch lines in `bin` and `core` (and in `jg-spawn.sh`, `jg-brief.sh`, `jg-dod-lib.sh`); it reads only the shipped table (screen: none).
