# Delivery style

Delivery style: run `done-done run delivery-style` (`bash journeys/delivery-style.sh`, which runs `tests/jg-delivery-style.test.sh` and writes its log and `steps.json` into the run's folder); it prints the row of each mode (and of the old words local-only and local-trunk, read as before) from `core/machines/styles/delivery-styles.tsv` through `bin/jg-delivery-style.sh`, refuses an unknown mode, and checks that no row names a prover, lands a lane with the old word and one with the new word in a fixture home (yolo off waits for a word, yolo on lands by itself; `tests/jg-local-mode.test.sh`), prints the knob of each of the four old words (pr or local), prints the local, review and trunk fact of each mode and the count of mode-branch lines in `bin` and `core` (and in `jg-spawn.sh`, `jg-brief.sh`, `jg-dod-lib.sh`); it reads only the shipped table (screen: none).
