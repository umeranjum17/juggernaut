# A landed lane is cleaned in the landing step, per lane, with a retry ladder for a refusal that only needs time

Cleanup at landing: run `done-done run trunk-landing` (its list includes `tests/jg-trunk-cleanup-at-land.test.sh`); over a fixture home with real git lanes and the real `core/trunk-landing/trunk-landing.sh runbatch`, it proves that each lane of a stack is cleaned at its own landed line while the lander still runs, that a refusal that only needs time (a slot allocation in progress) is retried at the ladder's delays and the lane is cleaned on the retry, that any other refusal (uncommitted changes) is tried once and gets its reason from `core/machines/cleanup-reason.states` and one alert, and that a time-only refusal that never clears is final after the ladder with one alert (screen: none).
