Sign-off feedback trail: run `JG_CODE_ROOT=<Juggernaut checkout> bash signoff/tests/jg-procevent-signoff.test.sh` (a card is marked Read only after the handler concludes its captured result, once; NOT_FOUND and a sign-off-axi without `feedback` keep the poll going) and `bash merge-card/tests/merge-card-e2e.sh` (`feedback:` lines: each card the brief or PR body names is marked acted on with the PR link once; reply, NOT_FOUND, older tool and refusal cases). Live: with a sign-off-axi 0.6.1+ build on `PATH` and a throwaway board and HOME, answer a card through `sign-off-axi serve`'s `api/answers`, run the adapter's `poll` after `jg-procevent.sh handled`, then `merge-card post` with a brief naming the card; the board's trail must show the read, then the reply with the link.
