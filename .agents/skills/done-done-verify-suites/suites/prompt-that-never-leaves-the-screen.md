# Prompt that never leaves the screen

Prompt that never leaves the screen: run `done-done run -- bash tests/jg-prompt-gate.test.sh` with the suite's log written into `$DONE_DONE_EVIDENCE_ROOT`; the real watcher over a tmux pane that keeps its permission prompt proves an approvable read is approved again every interval, a secrets read is rejected and the worker told why, Main is woken once at first sight. A second run, `done-done run -- bash tests/jg-autocompact-offer.test.sh`, proves a Claude pane parked on the autocompact offer gets one Esc from the watcher and a pane that only echoes the sentence in scrollback gets none (jg-3uo).
