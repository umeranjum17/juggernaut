# Teardown landed-work test (Go)

Teardown landed-work test (Go): run `bash tests/jg-teardown-core.test.sh` (or `done-done run -- bash tests/jg-teardown-core.test.sh` with the suite's log written into `$DONE_DONE_EVIDENCE_ROOT`); it drives `bin/jg-teardown-core.sh` against a lab origin and a fake forge and proves a merged PR landing, a PR merged into its own release base branch landing even though the default branch does not carry that merge while the same PR reported open still refuses, an open PR refusing with no fallback, the squash-flow content leg, and that a check that cannot run exits 2 rather than landing. `bash tests/jg-teardown.test.sh` (about 8 minutes) drives the same test through `bin/jg-teardown.sh`. For a port or change of the test, replay the previous shell test against the Go command over the forge's recorded pull requests (`core/teardown/README.md` names the replay and its control run); `bin/jg-teardown-core.sh landed` with the real `gh` shows the verdict on a real merged and a real open PR. The worktree safety check (`bin/jg-teardown-core.sh safety`: dirty, unpushed and unmerged reads, the local-only rule, the lock-blocked exit 3) is proved by the same suites and by the recorded replay in `core/teardown/README.md` (3,312 generated worktree states, shell at the base commit against the Go path, with a corrupted control that must fail); live, run it against a throwaway worktree of a real clone.
