# Flaky quarantine

A script flaky 3 times in 7 days runs but does not block, and gets one fix ticket: run `done-done run flaky-quarantine` (journey `tests/jg-trunk-quarantine.test.sh`, screen: none); the real `bin/jg-test-run.sh --gate` runs a lab script that always fails over a flaky ledger, and `core/trunk-landing/quarantine.sh` lists it on the third row with one ticket, never a second for the same script path (`quarantine.sh ticket`); with `config/quarantine` off the red still blocks, with it on the red is recorded as `JG_TEST_QUARANTINE_RED` and the gate passes; 10 green runs in a row take it off the list and it blocks again, a listing past 7 days expires with a note on its ticket, and a closed ticket lets a new one be filed. The log is `<run-id>.log` in the run folder.
