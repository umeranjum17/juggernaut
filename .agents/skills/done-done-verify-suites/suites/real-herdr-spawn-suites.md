# Real-Herdr spawn suites

Real-Herdr spawn suites: with the pinned bd and dolt on PATH (`JG_BEADS_TEST_BD`, `JG_BEADS_TEST_DOLT`), provision a named lab with `bin/jg-herdr-lab.sh provision <jg-lab-session>`, run `done-done run -- bash tests/jg-backend-herdr-workspace-per-home-e2e.test.sh` and `done-done run -- bash tests/jg-backend-herdr-presentation-e2e.test.sh` with the logs written into `$DONE_DONE_EVIDENCE_ROOT`, then `bin/jg-herdr-lab.sh teardown <session>`; the real `bin/jg-spawn.sh`, a real Treehouse pool and a real Herdr server prove a ship spawns only for a task that has a queued ticket in the home's Beads store (the suites file each fixture ticket through `herdr_test_backlog_ticket`, and requeue it before a respawn), that a primary home and a squad lead home each get their own workspace, and that the presentation projection, restart reclaim and lock-contention cases still hold. The presentation suite takes about fourteen minutes on a developer machine and about twenty-two on a CI runner. Without bd and dolt the suites skip plainly (screen: none).
