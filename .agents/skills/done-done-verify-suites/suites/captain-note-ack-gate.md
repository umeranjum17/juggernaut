# Captain note acknowledgement gate

Captain note acknowledgement gate: run `done-done run captain-note-ack-gate` (it invokes `bash journeys/captain-note-ack-gate.sh`, which runs `tests/jg-captain-note-ack-gate.test.sh` and the `test_captain_notes_lead_the_digest_before_the_lock` case of `tests/jg-session-start.test.sh`); the real `bin/jg-inbox.sh`, `bin/jg-wake-drain.sh` and `bin/jg-wake-bus.sh` over fixture homes prove an acknowledgement is refused while a captain inbox note in its batch has no reply and no drain acknowledgement, that a recorded reply or the note's own drain acknowledgement lets it through, that a note whose wake row was already retired still leads every later drain, and that the session digest prints the must-answer list before its lock and says nothing once the note is answered (screen: none).
