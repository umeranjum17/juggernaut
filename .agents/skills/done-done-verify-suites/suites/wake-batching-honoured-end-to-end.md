# Wake batching honoured end to end

Wake batching honoured end to end: run `done-done run wake-batching` (which runs `bash tests/jg-wake-batching.test.sh`); on three fixture homes with no `config/wake-routing` of their own it proves a lead's routine parent-channel lines route `batch` while a decision still wakes, a queued batch row no longer closes a Stop-owned watcher cycle while a `now` row behind it still re-delivers and the next drain still presents it, and a `done` carrying a key closes that decision on a `squad_lead` lane so its wait-timer episode stops climbing while an unrelated open wait keeps climbing. It fails on the unmodified tree, so Main's home-local stopgap cannot hide a defect (screen: none).
