# One-install stack

One-install stack: run `done-done run stack-install` (`bash journeys/stack-install.sh`, which runs `tests/jg-stack.test.sh`); in a throwaway HOME it runs the documented `bin/jg-stack.sh up`, proves the Go command, nats (with its accounts and the CAPTAIN stream) and dapr each report installed, enabled, a live pid and a listener, the wake engine and the reply router each run with a pid consuming their stream/consumer (confirmed on the server), a second run prints identical lines, and a broken nats config stops the run with one `STACK_FAILED` line. It skips with a named reason when the pinned releases or Go are unreachable. Wake engine and router traffic: run `bash tests/jg-wake-engine.test.sh` (accounts server; a real `bin/jg-wake-bus.sh raise` makes `bin/jg-bus.sh probe wake-engine` show handled 0 -> 1, a restart handles what arrived while down, a captain reply on `jg.captain.reply` reaches the router). Live on this machine, pre-merge: a temporary `JG_HOME`, tool prefix and `JG_STACK_UNIT_PREFIX=jgprobe` with `JG_STACK_SUPERVISOR=systemd` runs `bin/jg-stack.sh up` as real systemd user units, then `bin/jg-bus.sh probe` before and after a real wake.
