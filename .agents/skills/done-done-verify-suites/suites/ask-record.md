# Ask record joins an ask's measurements

Ask record: run `done-done run jg-ask-record` (`bash journeys/ask-record.sh` runs `tests/jg-ask-record.test.sh` and writes its log and the record `ask-record.json` into `$DONE_DONE_EVIDENCE_ROOT`); the real `bin/jg-ask-record.sh show` reads a fixture home's ticket moments, sealed done-done run record, trunk landing, proof, verify, in-use and release records and its git clone, and prints one record: the moments, ask-to-in-use and ready-to-in-use minutes, model turns, machine minutes, the run IDs from landing through verify, install and release, and one row per home with its waiver, verdict, behaviour and previous version. The log shows the candidate's own proof counted with its rerun and not a later tip's verify, `observe` binding a behaviour row to its home and version (the latest wins, an unobserved home named in `missing`), a pin-back leaving the live install row to date in-use, `turns` counting distinct model responses since the spawn, and an ask with no moments refused (screen: none).
