# Decision records

One decision per record, in the MADR 4 shape with a required Confirmation (a Juggernaut choice). A record is a real
decision, never an idea: status, context, two or more considered options, the decision, consequences and a
confirmation. After Accepted the body is never edited: only the Status line changes, and a new record supersedes it.
