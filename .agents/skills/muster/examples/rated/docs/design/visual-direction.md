# Visual direction: help desk bot

The look the captain picked on the board, so every screen built later follows it. Pictures are made with first-draft
and picked on design cards; this file links the picks and never re-draws them.

## Direction
- Picked direction: "Calm paper" (design card hd-dir-1, picked 2026-11-22)
- Why this one: "It feels like a person is listening, not a dashboard."
- Type, colour and density: a humanist sans at 16 px; warm off-white with one accent; roomy lines.

|---|---|---|---|

## Rules for screens not drawn
- One accent colour, only for the next action.
- Every answer shows its answer source under it.
- An error says what to do next, in the glossary's words.
