# Decision records

One decision per record, in the MADR 4 shape with a required Confirmation (a Juggernaut choice: MADR's minimal
template has none and its full template marks it optional). A record is a real decision, never an idea: it has a
status, a context, two or more considered options, the decision, its consequences and a confirmation that names the
check enforcing it. After Accepted the body is never edited: only the Status line changes, and a new record
supersedes it.
